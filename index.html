PraiseHim para escritorio

Se instala en la computadora que proyecta y abre el proyector y el monitor de retorno en su pantalla, sin permisos ni ventanas que acomodar. Reconoce cada monitor aunque cambies los cables. Se puede usar con cualquier plan.

Windows Linux (.deb) Más información

En Windows puede que aparezca un aviso antes de abrir el instalador: elegí Más información → Ejecutar de todas formas.

Que Linux la actualice sola

Un .deb instalado a mano no se actualiza nunca. Agregando el repositorio, la app se actualiza con el resto del sistema: 

curl -fsSL https://joririarte.github.io/praisehim-desktop/praisehim-apt.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/praisehim.gpg
echo "deb [signed-by=/usr/share/keyrings/praisehim.gpg] https://joririarte.github.io/praisehim-desktop/apt ./" \
  | sudo tee /etc/apt/sources.list.d/praisehim.list
sudo apt update && sudo apt install praisehim-escritorio

Desde ahí, sudo apt upgrade la mantiene al día. En Windows se actualiza sola.

Acá se publican solo los binarios: el código de PraiseHim vive en un repositorio privado. El sitio es praisehim.com.ar.
